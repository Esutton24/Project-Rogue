## 📖 About

**Project Rogue** is a wave-based roguelike set on a spooky suburban
cul-de-sac. You choose a Halloween-themed class — Ninja, Cowboy,
Superhero, or Pirate — and defend the neighborhood's buildings from
oncoming hordes of enemies.

Each wave runs on a timer. Survive the clock, protect the houses, and
every **5 waves** you'll get to pick an upgrade tailored to your class.
If the buildings fall, the night is over.

---

## 🎮 Gameplay

| Phase | Description |
|---|---|
| Start | Players choose a class before starting. |
| Conflict | Enemies move toward the buildings. |
| Defend | Player fights off waves and protects buildings from destruction. |
| Upgrade | Player selects an upgrade after every 5 waves. |
| Lose | Player fails to prevent the destruction of the buildings. |

## 🥷 Classes

Every class has a **ranged** and a **melee** option, so you can fight
your way however you like.

| Class | Ranged Weapon | Melee Weapon | Notes |
|---|---|---|---|
| 🥷 Ninja | Ninja Stars | Dash Strike | Fast, precise hits |
| 🤠 Cowboy | Dual Revolvers | Lasso / Whip | Reload management matters |
| 🦸 Superhero | Laser | Punch | Raw power fantasy |
| 🏴‍☠️ Pirate | Cutlass | Cannonball | Melee based, hard hitting |

---

## ⬆️ Upgrades

Chosen after every 5 waves of survival.

| # | Upgrade | Effect |
|---|---|---|
| 1 | Attack Speed Up | Faster attack rate |
| 2 | Movement Speed Up | Get around the cul-de-sac quicker |
| 3 | Slow Ability | Slow enemies in range |
| 4 | Explode Ability | Detonate a burst of damage |
| 5 | Projectile +1 | One extra projectile per shot |
